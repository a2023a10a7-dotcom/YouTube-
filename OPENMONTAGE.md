# OpenMontage production engine

The production engine is tracked at `vendor/OpenMontage` as an upstream Git submodule.

- Read [integration and setup notes](docs/OPENMONTAGE-INTEGRATION.md).
- Upstream project: https://github.com/OpenMontageInc/OpenMontage
- Upstream license: GNU AGPL-3.0.

A normal clone must include submodules: `git clone --recurse-submodules ...`.

**Status:** upstream engine linked in this repository. End-to-end adapter, multi-reference style-profile ingestion, autonomous asset selection policy, and a verified final MP4 remain separate work and must not be described as completed until tested.
