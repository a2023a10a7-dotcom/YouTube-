# Offline documentary editorial package

This folder contains a source-grounded research report, an English narration draft, a scene-by-scene director blueprint, and the source register for **The Great Molasses Flood of 1919**.

This package is intentionally prepared without a paid model API call. The blueprint is an editorial plan; its footage assets have not yet been acquired, and it is not a rendered video.

Updating any file in this folder triggers the Telegram delivery workflow on the `integrate/openmontage` branch.
